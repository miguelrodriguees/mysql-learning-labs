# Meus estudos de MySQL

Neste repositório coloquei alguns exercícios que fiz durante as aulas de MySQL.

Tem atividades de criação de bancos e tabelas, relacionamentos, inserção de dados e consultas. Também coloquei o arquivo de uma modelagem feita no MySQL Workbench.

## Exercícios

```text
01-cadastro-aluno/
02-academia/
03-banco-de-vendas/
04-modelagem-produtos/
05-jogo-da-velha/
```

A pasta do Jogo da Velha tem a parte do banco de dados. O código em Java está no repositório `jogo-da-velha-java`.
