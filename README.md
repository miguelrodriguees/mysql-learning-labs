# Meus estudos de MySQL

Este repositório reúne exercícios e bancos de dados que fiz durante as aulas de MySQL.

Aqui estão atividades em que pratiquei criação de bancos e tabelas, chaves primárias e estrangeiras, relacionamentos, inserção de dados e consultas com `SELECT`.

Também há exercícios com `WHERE`, `LIKE`, `BETWEEN`, `ORDER BY`, `LIMIT`, `COUNT`, `SUM`, `AVG` e `GROUP BY`.

## Organização

```text
01-cadastro-aluno/
02-academia/
03-banco-de-vendas/
04-modelagem-produtos/
05-jogo-da-velha/
```

Os arquivos foram desenvolvidos no MySQL Workbench durante meus estudos. Estou mantendo os exercícios organizados aqui para acompanhar minha evolução em banco de dados.

O Jogo da Velha também possui um repositório próprio com a parte em Java e a conexão com MySQL: `jogo-da-velha-java`.
